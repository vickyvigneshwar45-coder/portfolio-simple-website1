# Personal Portfolio Website

## 📌 About the Project

This project is a **Personal Portfolio Website** created using **HTML and CSS**. The website consists of two pages designed to showcase my personal information, skills, projects, and contact details.

The main goal of this project is to create a simple, clean, and user-friendly portfolio website while practicing the fundamentals of front-end web development.

## ✨ Features

* Clean and simple user interface
* Two-page portfolio website
* Responsive and user-friendly layout
* About Me section
* Skills section
* Projects section
* Contact information
* Navigation between pages
* Custom styling using CSS

## 🛠️ Technologies Used

* **HTML5** – Used to structure the web pages
* **CSS3** – Used for styling, layout, colors, and design

## 📄 Pages

### 1. Home / About Page

Introduces me and provides basic information about my background, interests, and skills.

### 2. Projects / Contact Page

Showcases my projects and provides contact information so visitors can learn more about my work and connect with me.
